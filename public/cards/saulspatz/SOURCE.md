# Source and license

These 53 SVG files (52 card faces + `back.svg`) are vendored from the
`Decks/Vertical2/svgs/` folder of:

https://github.com/saulspatz/SVGCards

Card files were renamed from the upstream `{suit}{rank}.svg` naming
(e.g. `heart6.svg`, `spadeQueen.svg`) to this project's `{suit}-{rank}.svg`
convention (e.g. `hearts-6.svg`, `spades-12.svg`); `blueBack.svg` was
renamed to `back.svg`. No other changes were made.

The README also documents the provenance of the individual art assets
Saul Spatz built on: the face-card illustrations come from a playing
card set by Byron Knoll (Wikimedia Commons), the card backs from
openclipart.org, and the jokers (unused by this project) by Brian
Kroll (also Wikimedia Commons) — all stated by the original README to
be public domain.
